## 3. 具体改动

全部为**新建 / 复制**，未修改 `out/` 下原有脚本，也未改动任何 C# 源码。

| 文件 | 操作 | 说明 |
| --- | --- | --- |
| `~/.local/bin/sourcegit-launch.sh` | 新建（+x） | ASCII 路径包装脚本：`set -e` → 校验 `REAL=/home/m700s/文档/outPs/sourcegit/build/loongarch64/sourcegit-launch.sh` 可执行，否则报错退出 1 → `exec "$REAL" "$@"` 转发 |
| `~/.local/share/applications/sourcegit.desktop` | 新建（+x） | 应用菜单项：`Type=Application`、`Name/Name[zh_CN]=SourceGit`、`Comment=SourceGit 图形 Git 客户端`、`Exec=`/`TryExec=`=/home/m700s/.local/bin/sourcegit-launch.sh、`Icon=/home/m700s/.local/share/icons/sourcegit.png`、`Terminal=false`、`StartupNotify=true`、`StartupWMClass=SourceGit`、`Categories=Development;RevisionControl;` |
| `~/.config/autostart/sourcegit.desktop` | 新建（+x） | 登录自启项：同上 Exec/TryExec/Icon，Comment 改为「登录后自动启动 SourceGit」，额外带 `X-GNOME-Autostart-enabled=true`、`X-KDE-autostart-after=panel` |
| `~/.local/share/icons/sourcegit.png` | 复制 | 源：`build/resources/_common/icons/sourcegit.png`（37 445 字节，256×256 RGBA） |
| `~/桌面/SourceGit.desktop` | 新建软链接 | `ln -sfn → /home/m700s/.local/share/applications/sourcegit.desktop`，与桌面既有图标风格一致 |

**设计要点**

* 所有 `Exec=` 一律指向纯 ASCII 的 `~/.local/bin/sourcegit-launch.sh`，
  规避 `文档/outPs/...` 中文路径在桌面项 `Exec` 中的解析风险；
  中文路径只出现在脚本内部的带引号字符串中，由 bash（UTF-8）处理。
* 包装脚本仍然转发到原启动器，因此 **完整保留** 上一场会话的 GTK/FreeType
  崩溃规避逻辑（生成 `no-gtk/libgtk-3.so.0` 假 ELF 并前置 `LD_LIBRARY_PATH`，
  详见 [2026-11-10-打开文件夹崩溃分析.md](2026-11-10-打开文件夹崩溃分析.md)）。

## 5. 交付与用法

| 用途 | 位置 |
| --- | --- |
| 桌面快捷方式 | `~/桌面/SourceGit.desktop` |
| 应用菜单项 | `~/.local/share/applications/sourcegit.desktop` |
| 开机/登录自启 | `~/.config/autostart/sourcegit.desktop` |
| 启动包装脚本 | `~/.local/bin/sourcegit-launch.sh` |
| 应用图标 | `~/.local/share/icons/sourcegit.png` |

* 手动启动：双击桌面 `SourceGit` 图标，或在 KDE 应用菜单搜「SourceGit」。
* 只要手动不要自启：`rm ~/.config/autostart/sourcegit.desktop`
* 只要自启不要桌面图标：`rm ~/桌面/SourceGit.desktop`

## 6. 遗留问题 / 后续建议

* 两个桌面项的触发时机都是 **图形会话登录**，不是 TTY 阶段的「开机即拉起」；
  若真正需求是让 DSH 网页版（`http://127.0.0.1:3080`）常驻，
  应改用 `systemd --user` 服务（本次未实施，待用户确认）。
* 自启文件权限最终为 `711`（`-rwx--x--x`），系 `chmod +x` 与 umask 叠加所致，
  不影响执行，但建议复核。
* 图标与 `Exec=` 均为绝对路径，日后迁移用户目录需同步更新两个桌面项。
* 首次实测中「第二实例秒退」未完全归因（已排除单实例逻辑），
  推测与 harness 的进程组 SIGTERM 清理有关，属测试环境副作用而非应用缺陷。
