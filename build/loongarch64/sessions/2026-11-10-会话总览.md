## 2026-11-11 续：迁移到本机 LoongArch ABI 2.0（3B6000 / Loongnix 25）

上述四场会话都在 **3A6000 / Loongnix 20（ABI 1.0）** 上完成。2026-11-11 换到
**3B6000 / Loongnix 25（ABI 2.0，ELF e_flags `0x43` / OBJ-v1）** 后重新适配并实机验证，
详见 [2026-11-11-ABI2适配.md](2026-11-11-ABI2适配.md)。要点：

* .NET 运行时与 loongarch64 NuGet 包仍是 **ABI1 构建**，本机靠
  `/lib64/ld.so.1 → /usr/local/app-compat/.../ld-2.28.so` 的兼容层运行（libc 2.28 / libicu 67 /
  libssl 1.1 / freetype 2.11 / fontconfig 1.12），因此无需重编 dotnet/runtime；
* 本机没有系统 dotnet，muxer 改从 NuGet 的
  `runtime.linux-loongarch64.Microsoft.NETCore.DotNetHost` 8.0.34 取；
* 必须用 NuGet `packageSourceMapping` 把 SkiaSharp/HarfBuzz 原生库与 loongarch64 运行时
  固定到 loongnix 源，否则 `out/` 里会缺 `libSkiaSharp.so`；
* 本机 Avalonia 走 xdg-desktop-portal，不再需要无条件禁用 GTK；
* 系统 Git 2.47.2 已满足 2.31，无需 `~/.local/bin/git`；
* deb 依赖改为 `libicu76 | libicu72 | libicu67`、`libssl3t64 | libssl3 | libssl1.1` 等本机包名。
